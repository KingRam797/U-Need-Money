# Mobile Playtest

Test representative narrow and tablet viewports. Verify primary flows without hover or mouse unless explicitly required; reachable controls; touch targets; scrolling; orientation; safe areas; virtual-keyboard behavior; and clipping or overlap of critical UI. For games, check simultaneous and repeated touch input where relevant.

Fix only within scope. Recheck the affected flow and note device or browser limits not directly tested.
