# Frontend Pass

Identify the current design system, key screens, user goal, and existing brand assets. Improve the highest-impact issues in hierarchy, spacing, typography, color, responsiveness, interaction states, and accessibility.

Preserve functional flows and confirmed copy. Reuse sound components and tokens. Avoid generic redesigns, speculative features, and unnecessary asset replacement. Verify affected screens at representative desktop and mobile widths and run relevant checks.
